How this works

Reports are GitHub issues on , sent with the + Add missing tracks button on any set. Status follows the issue: open is New, the accepted label is Accepted, closed as completed is Merged into the tracklists, closed as not planned (or labelled wontfix / invalid / duplicate) is Rejected. This page reads GitHub's public API, which allows about 60 loads an hour per visitor, so results are cached for a few minutes.
